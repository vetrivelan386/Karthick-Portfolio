# Karthick Portfolio — Export Sourcing & Buyer Liaison

A business website developed for Karthik Raja Muthumanickam to present export sourcing services and connect international buyers with Indian manufacturers.

**Live Website:** https://karthick-portfolio-sigma.vercel.app

## Project Overview

This project is a professional website for an export sourcing and buyer liaison business based in Chennai, India. It explains the sourcing process, introduces the business, and provides contact options for potential international buyers.

## Key Sections

- **Business Introduction** — Profile and overview of export sourcing services.
- **Sourcing Process** — Requirement collection, supplier shortlisting, sampling, quotation, quality checks, and shipping coordination.
- **Product Sourcing** — Information for buyers looking to source products from India.
- **Trust & Transparency** — Explains the proposed buyer-supplier coordination process.
- **Contact & Enquiries** — WhatsApp and email contact options.

## Technologies Used

- HTML5
- CSS3
- Responsive web design
- Google Fonts
- Vercel deployment
